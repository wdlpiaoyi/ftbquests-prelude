# FTB Quests: Prelude

**不进入世界，也能打开任务书。**

这是 FTB Quests 的非官方客户端附属模组：在主菜单、选择世界、创建世界、世界加载界面就能浏览与编辑本地任务文件，并查看单人存档的任务进度。

> 本模组与 FTB（Feed The Beast）官方无关，未获其认可或背书。

## 它解决什么问题

FTB Quests 的任务书只能在进入世界后打开。整合包作者调任务、检查进度，或者你想在开档前先看看任务线，都得先读档进世界。

这个模组把这本任务书搬到了世界之外。

## 功能特性

- **世界之外打开任务书** —— 标题界面、选择世界、创建世界、加载界面的右上角都有书本按钮，也可以绑定快捷键（默认未绑定，在「按键绑定」里设置）。
- **本地编辑模式** —— 开启后所有任务可见可改：任务、章节、任务目标（Task）、奖励、奖励表。改动直接写入 `<config>/ftbquests/quests`。
- **写入有保险** —— 防抖自动保存 + 关闭界面即保存 + 每次保存前自动生成带时间戳的备份（保留份数可配置），并自动清理孤立的章节 / 奖励表文件。
- **查看单人存档进度** —— 在任务书内打开任意存档的任务进度，支持多队伍切换；队伍行显示成员数量，右键可列出具体成员。
- **原生外观** —— 界面、主题、图标全部复用 FTB Quests / FTB Library 自身资源，风格统一；资源包修改 FTB 图标时，这里也会同步生效。

## 环境要求

- Minecraft **1.20.1**
- Forge **47.x**
- 依赖 **FTB Quests**（及其依赖：FTB Library、FTB Teams、Architectury API）
- **客户端模组**（`displayTest = IGNORE_ALL_VERSION`），装了它的客户端可以进入未安装本模组的服务器

## 安装

1. 安装 Minecraft 1.20.1 + Forge 47.x。
2. 安装 FTB Quests 及其依赖。
3. 把 `ftbquests_prelude-1.0.0.jar` 放进 `mods/` 文件夹。

## 使用方法

**打开本地任务书**
点击右上角的书本按钮，或在「选项 → 控制 → 按键绑定 → FTB Quests: Prelude」中绑定快捷键。

如果在选择世界界面选中了某个存档，或正在加载某个世界，按钮会直接打开**该存档的任务进度**。

**查看本地任务进度**
任务书右下角的保存图标按钮：若已经在看某个存档，会直接打开该存档的队伍列表；否则先选存档、再选队伍。悬停队伍可看成员数量，**右键**队伍可展开成员列表。

**编辑模式**
用任务书里的编辑按钮切换，或在配置中设置 `editorModeDefault = true` 默认开启。

## 配置文件

位置：`<config>/ftbq_prelude/ftbquests_prelude-common.toml`

- `backupCount`（默认 `10`，范围 `0`–`1000`）：保留的备份数量，`0` 表示关闭备份。
- `autoSaveOnClose`（默认 `true`）：关闭本地任务界面时保存改动。
- `autoSaveDebounceSeconds`（默认 `5`，范围 `1`–`300`）：停止编辑多久后自动保存。
- `editorModeDefault`（默认 `false`）：打开本地任务书时默认进入编辑模式。
- `showEntryButtons`（默认 `true`）：是否显示菜单界面的入口按钮（快捷键不受影响）。
- `showSaveProgressButton`（默认 `true`）：是否显示任务书内的进度按钮。

## 数据与备份位置

- `<config>/ftbquests/quests`：读取与编辑的本地任务数据。
- `<config>/ftbq_prelude/backups`：任务文件夹的时间戳备份（本模组自己的目录）。
- `<存档>/ftbquests/<队伍uuid>.snbt`：单人存档的任务进度（只读）。
- `<存档>/ftbteams/...`：FTB Teams 数据（只读，用于列出队伍与成员）。

## 已知限制

- **不替代服务端同步**：多人游戏中，任务数据与进度仍以服务端为准。
- 未在本地缓存过的多人任务文件可能不可用，多人进度不保证。
- 不支持在菜单里编辑多人任务，请进入世界后使用原生任务书。
- 目前仍属原型阶段，部分流程未完全复用原生 UI，交互可能与世界内任务书略有差异。
- 队伍成员从本地存档数据解析，从未在本机出现过的玩家可能显示为短 UUID。

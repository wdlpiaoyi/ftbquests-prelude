An unofficial addon mod for **FTB Quests** on **Minecraft 1.20.1 (Forge)**.

|---|---|

## Repository layout

```
.
├── Reference/      Third-party resources (reference source, jars, docs). Git-ignored.
```

upstream FTB Quests source used as a development reference.
